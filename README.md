# Caesar Cipher – Text Encryption and Decryption

## 1. Project Overview

Caesar Cipher is a beginner-level cybersecurity project that demonstrates the basic concepts of cryptography through text encryption and decryption.

It uses a substitution technique in which each letter in a message is shifted by a fixed number of positions in the alphabet.

## 2. Project Objectives

- Understand the fundamentals of cryptography.
- Convert plaintext into encrypted text (ciphertext).
- Recover the original message through decryption.
- Understand the role of shift keys in encryption.
- Practise basic cybersecurity programming concepts.

## 4. Working Principle

The Caesar Cipher works by shifting each alphabet letter according to a numerical key.

For example:

**Original Text:** HELLO

**Shift Key:** 3

**Encrypted Text:** KHOOR

During decryption, the letters are shifted backwards by the same number to recover the original message.

## 5. Main Features

- Text encryption.
- Text decryption.
- User-defined shift key.
- Alphabet shifting mechanism.
- Simple and beginner-friendly implementation.

## 6. Technologies Used

- Python

## 7. Project Workflow

1. Enter the original message.
2. Enter the shift key.
3. Select encryption or decryption.
4. Process the message using the Caesar Cipher algorithm.
5. Display the resulting encrypted or decrypted text.

## 8. Testing

The application can be tested using:

- Different plaintext messages.
- Different shift values.
- Uppercase and lowercase letters.
- Empty input.
- Special characters and spaces.

## 9. Limitations

Caesar Cipher is a basic educational encryption technique. It is not suitable for protecting confidential information because its small key space makes it easy to break.

## 10. Educational Purpose

This project is developed for academic and cybersecurity learning purposes. It helps students understand the fundamentals of substitution ciphers and the basic working principles of encryption and decryption.
